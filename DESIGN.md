# DESIGN.md — ECAISSE (Industrial Neo-Fintech)

## Aesthetic Direction
- **Style:** Industrial Neo-Fintech / Precision POS. Clean, high-contrast, mathematical precision with generous airy whitespace and crisp typography.
- **Palette:** 
  - Backgrounds: Pure white (`#FFFFFF`) and tinted neutral canvases (`#F8FAFC`).
  - Text & Borders: Deep slate/obsidian (`#0F172A`, `#334155`) with fine micro-borders (`#E2E8F0`).
  - Accent (Green): Precision Emerald (`#059669`, `#10B981`, `#ECFDF5` for subtle badge fills).
- **Typography:** Geist / Inter Tight / Outfit with tabular numeric formatting (`font-tabular-nums`) for financial amounts.
- **Motion:** Fast, spring-based micro-interactions (`transition-all duration-200 ease-out`).

## Core Tokens
- Radius: `rounded-xl` (12px) for cards, `rounded-lg` for interactive buttons and inputs.
- Shadows: Subtle multi-layered shadows (`shadow-sm`, `shadow-pervasive`).
- Spacing: Airy padding (`p-6` to `p-8` for sections, `gap-6` grid layouts).
